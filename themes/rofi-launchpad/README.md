# Rofi Launchpad
This is a theme for Rofi inspired on Apple macOS.

To use it, you need install Rofi. That's the command:

```bash
sudo apt install rofi
```

Check if exists the directory `~/.config/rofi` running the following:

```bash
ls -d ~/.config/rofi
```

**If you hasn't this directory, run the following command in terminal:**

```bash
mkdir ~/.config/rofi
```

Then you take the file [launchpad.rasi](/themes/rofi-launchpad/launchpad.rasi) and move to:

```bash
~/.config/rofi
```

## Moving Theme
Take the file [launchpad.rasi](/themes/rofi-launchpad/launchpad.rasi) and move to the following:

```text
~/.config/rofi
```

## Using
Run the following command:

```bash
rofi -show drun -theme ~/.config/rofi/launchpad.rasi
```
